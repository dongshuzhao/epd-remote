# 内置字体

`wqy-bitmapsong12.woff2` / `wqy-bitmapsong16.woff2` 是 **文泉驿点阵宋体**（WenQuanYi Bitmap Song）12px 与 16px 两档，由官方 TTF 转成 woff2（仅换容器，字形数据未改），共约 2.7 MB。

模板正文用它渲染。注意这两个字体的 **em 框不等于点阵尺寸**：

- 12px 点阵：`unitsPerEm = 1500`，1 设计像素 = 100 单位 → em = 15 设计像素，汉字步进 1200 单位 = 12 设计像素
- 16px 点阵：`unitsPerEm = 1800`，1 设计像素 = 100 单位 → em = 18 设计像素，汉字步进 1600 单位 = 16 设计像素

所以 CSS 字号要取 **15 的整数倍**（12 点阵）或 **18 的整数倍**（16 点阵），字形才 1:1 压在像素格上。按 16px 渲染 16 点阵字体是错的——1 设计像素会变成 0.889 CSS px，笔画厚薄不均、边缘发灰。

`templates.js` 里的档位只保留 15px（12 点阵，仅小屏用）和 18/36/54/72（16 点阵），并按画布高度选档（`tplBodySize`）：高度 <200 用 15，<420 用 18，<760 用 36，更大用 54。16 点阵字形细节明显好于 12 点阵放大，所以不用 30/45/60 那些 12 点阵的倍数档。绘制时基线与对齐原点都取整，避免子像素定位把点阵糊掉。

标题不内置字体，用系统细黑栈（华文细黑 STXihei → Hiragino Sans GB W3 → 苹方 → 微软雅黑 Light → 思源黑体 → sans-serif），字重 300（细体），`bold` 也只提到 400，避免又变回粗黑。彩色标题栏上的反白白字是例外，用 500：细笔画反白后抗锯齿灰边会在三色屏打包时被判成红色，笔画会断；`tplHardenBar()` 还会把标题栏区域硬二值化成纯白/纯强调色两种像素，保证反白笔画完整。

## 许可

文泉驿点阵宋体以 **GPL v2 及以上，附字体嵌入例外条款**（GPLv2+ with font embedding exception）发布，可自由使用与再分发。项目分发时请保留本说明。

- 上游项目：<http://wenq.org/>
- 字体嵌入例外允许把字体嵌入文档/页面而不因此传染 GPL
